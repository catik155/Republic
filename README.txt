РЕСПУБЛИКА — DESKTOP / 3D ПРОТОТИП (Alpha 0.14)

Это рабочая основа Windows desktop-приложения на Electron с Three.js WebGL 3D-сценой.

Включено:
- стартовое меню создания государства (не вход сразу в карту);
- параметры страны, min/max игроков, партии, AI, сложность, год;
- фиксированная вручную описанная планировка города (не случайный layout);
- 3D-объёмные районы с цветами, контуром и подписями;
- фиксированные здания с фасадами, крышами, этажностью и тенями;
- дороги, тротуары, небольшие парки;
- пешеходные точки, размещённые вдоль пешеходных коридоров;
- вращение/наклон/масштаб камеры мышью через OrbitControls;
- выбор района, инспектор и переключение слоёв карты.

Пока не готово:
- это 3D-визуальный прототип, не полноценная игровая симуляция;
- выбор настроек не запускает все системы экономики/политики;
- сетевой режим лишь обозначен в стартовых настройках, подключение не реализовано здесь;
- EXE в архиве не приложен, поскольку сборка требует установки npm-зависимостей и запуска electron-builder на машине с Windows (или CI Windows runner).

Сборка EXE в Windows:
1. Установить Node.js LTS.
2. Распаковать архив в папку.
3. Открыть терминал в republic_desktop3d.
4. Выполнить: npm install
5. Проверить: npm run check
6. Собрать переносимый EXE: npm run dist:win
7. EXE появится в папке dist.

Запуск для разработки:
 npm install
 npm start

Зависимости: Electron, electron-builder, Three.js.
