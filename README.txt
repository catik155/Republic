РЕСПУБЛИКА — DESKTOP / 3D ПРОТОТИП (Alpha 0.15)

Основа настольного Windows-приложения Electron + Three.js.

В Alpha 0.15 непосредственно в GitHub внесены:
- исправлен селектор canvas предпросмотра стартового меню (preview вместо previewCanvas);
- тематические слои районов стали взаимоисключающими и при снятии выбора возвращают базовые цвета;
- проверяются настройки старта: min/max игроков, число партий, ИИ и год;
- выбор онлайн-режима блокируется с ясным сообщением, пока сетевой мультиплеер не реализован;
- версия package.json и runtime preload обновлена до 0.15.0.

Управление картой:
- ЛКМ и OrbitControls: вращение камеры;
- колесо мыши: масштаб;
- клик по району: инспектор;
- кнопки карты и тематические слои: районные данные.

Запуск разработки:
1. Установить Node.js LTS.
2. Клонировать/скачать репозиторий.
3. В папке проекта выполнить npm install.
4. npm run check — проверка синтаксиса.
5. npm start — запуск приложения.

Windows portable EXE:
- npm run dist:win
- файл появится в папке dist после успешной сборки.

Пока не реализовано:
- реальный онлайн-мультиплеер, лобби, P2P/relay и синхронизация;
- полноценные игровые системы экономики, политики, выборов и ИИ;
- EXE Alpha 0.15 не собран и не проверен в этой среде.

Технические стек: Electron, Three.js, Electron Builder.
